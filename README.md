## Projects

| Project | What it does |
|---------|--------------|
| [**AI Mock Interview Analyzer**](https://ai-mock-interview-analyzer.streamlit.app/) | Reads your resume, picks an interview track for your domain, takes voice or text answers, and scores them with NLP and a trained ML model. Plotly dashboard at the end. |
| [**Solar Cell Power Prediction**](https://solar-cell-power-prediction-hgwfeynyjki2hx6bach3vp.streamlit.app/) | Predicts solar power output (Random Forest R² 98.64%, XGBoost 98.57%) with fault detection, health score and efficiency score. |
| **Resume Suitability Evaluator** | End-to-end ML web app that scores how suitable a resume is for a role. |
| **GaN Semiconductor ML** | ML on GaN semiconductor data, using physics-grounded synthetic data generation. |
| **Smart Factory Dashboard** | Industry 4.0 monitoring dashboard built on the AI4I 2020 predictive maintenance dataset. |
