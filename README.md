## 🚀 Featured projects

### 🎮 [BuzzIn](https://github.com/mohdkaunain/Blitzv4) &nbsp;·&nbsp; [buzzin.site](https://buzzin.site)
A real-time multiplayer game-night platform on **Monad**. A host creates a room, players scan a QR code and get an embedded wallet automatically, an AI Game Master adjusts difficulty from live room metrics, and the whole game settles on-chain in a single transaction.
`Next.js` `TypeScript` `Supabase` `Solidity` `Monad` `Gemini`
> Server-authoritative game engine, 129 unit and integration tests, and an 86-check end-to-end flow suite.

### 🎙️ [AI Mock Interview Analyzer](https://ai-mock-interview-analyzer.streamlit.app/)
Reads your resume, picks an interview track for your domain, takes voice or text answers, and scores them with NLP plus a trained ML model. Plotly radar dashboard at the end.
`Python` `Streamlit` `Scikit-learn` `PyMuPDF` `Plotly` `NLP`

### ☀️ [Solar Cell Power Prediction](https://github.com/mohdkaunain/Solar-Cell-Power-Prediction) &nbsp;·&nbsp; [Live app](https://solar-cell-power-prediction-hgwfeynyjki2hx6bach3vp.streamlit.app/)
Predicts solar plant output with **Random Forest (R² 98.64%)** and **XGBoost (R² 98.57%)**, plus fault detection, health score and efficiency score.
`Python` `Scikit-learn` `XGBoost` `Streamlit`
